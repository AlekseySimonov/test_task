# Тестовое задание

## Условия задачи

Есть массив уникальных не отсортированных чисел от 1 до 100, из него удалили одно
случайное число, нужно найти это число, не используя сортировку.
Решение должно представлять из себя js файл, в котором написаны функции, в которые
передают массив. Функции должны возвращать недостающее чисто.

Решений у задачи много, поэтому просим написать все решения, которые успеете придумать
и реализовать за 30 минут.
